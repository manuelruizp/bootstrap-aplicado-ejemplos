# Pistas

Completa el manejador de confirmación en una copia de practica/inicio. Identifica la fila mediante seleccion, deshabilita confirmar para evitar doble acción, retira fila y grupo de acciones, llama filtrar y sincronizarAcciones, recalcula resumen desde filas restantes y cierra con la instancia de Bootstrap. Marca eliminado para decidir el foco al cerrar. No modifiques datos antes del clic confirmatorio.

Cancelar y Escape deben mantener tres filas y 117 unidades. Después de eliminar P002 deben quedar dos filas y 37 unidades. Si buscas P003 y lo eliminas, el contador debe ser 0 de 2. Borrar búsqueda muestra las otras dos filas. Recargar restaura tres.
