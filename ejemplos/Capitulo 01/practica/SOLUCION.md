# Solución de referencia

Abre solucion/index.html después de intentar el ejercicio. Se conserva el resultado principal del capítulo en ../final/index.html (ruta desde practica).

Cambios respecto a final:
- Cuarto li con list-group-item py-3, código P004 y 40 unidades; párrafo con mb-0. Repetir el mismo patrón mantiene la agrupación y el espaciado.
- El resumen indica Cuatro artículos.
- El enlace dice Consultar existencias y utiliza btn btn-success. btn conserva la base del componente; btn-success cambia la variante visual. href="#productos" conserva el destino. Esta elección sirve para observar variantes; una aplicación completa debe mantener un criterio coherente para sus acciones.

Comprueba cuatro artículos, ajuste del nombre largo, foco y activación con teclado, CSS y JavaScript sin errores. Un nombre de CSS inexistente produce un fallo de carga y deja de aplicar los estilos de Bootstrap; restaurar la URL recupera la presentación. Los cambios de las herramientas de desarrollo no se guardan en el archivo.

La práctica no añade almacenamiento. Para continuar con el capítulo 2 usa final, no esta variante.
