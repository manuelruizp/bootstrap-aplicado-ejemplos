# Solución de referencia
solucion contiene las tres pantallas completas. Los HTML conservan footer#pie-comun y layout.js crea su párrafo con textContent. El menú se sigue montando una sola vez y tema.js conserva su responsabilidad. El contenido de main y los scripts del inventario coinciden con final.
El texto es fijo, no una operación de soporte real. El pie requiere JavaScript; noscript sigue ofreciendo navegación básica. Para entregar el pie sin depender del navegador, compón el HTML con una plantilla del servidor o durante la compilación.
