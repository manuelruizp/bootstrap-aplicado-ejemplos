# Pistas
1. Compara el footer de las tres páginas; conserva su etiqueta semántica y clases.
2. Deja un único footer con id pie-comun. No añadas un footer dentro de otro.
3. En layout.js busca ese destino, crea un párrafo y asigna su texto con textContent.
4. Cambia el mensaje una sola vez y revisa las tres páginas, ambos temas y la navegación.
5. Sin JavaScript el pie quedará vacío: registra esa limitación y considera composición de servidor o de compilación.
